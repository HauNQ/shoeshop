# shoeshop
ShoeShop is a RESTful API project developed to revise and strengthen my knowledge of Java Core and Spring Boot. The project provides backend services for an online shoe store, allowing clients to manage products, users, shopping carts, and orders through RESTful endpoints.

# Integrate CICD For Application through Gitlab-runner
1. Go to the settings of the repository
2. Add new runner
3. Prepare a server to host the runner
4. Connect the runner with the repository
5. Write guideline for the runner to build and run application in .gitlab-ci.yml

# Deploy application
1. Prepare Dockerfile and Docker-compose.yml
2. Test running in development environment
3. Prepare a server installed Docker
4. Pull source from git
5. Prepare environment variables in .env file
6. Run docker-compose up -d 
7. Test application
